# Wishlist Nicky

Web: https://marvainstein.github.io/wishlistnicky/

Misma base que [wishlistcumple-](https://github.com/marvainstein/wishlistcumple-) con otra estética.

- Los regalos están en `src/data/products.ts` y sus fotos en `public/products/`.
- Cada cambio que llega a `main` se publica solo (GitHub Actions → Pages).
- Reservas compartidas: un proyecto de Supabase propio (`src/config.ts`). Sin claves, funciona en modo local.

Desarrollo local: `npm install` y `npm run dev`.
